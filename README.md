## ♡ About This Repository

**YENYEN ARCHIVE** is a personal digital archive created to store, organize and manage various files and resources.

This repository serves as a centralized storage space for digital assets, including configuration files, application resources, images, and other useful data.

Everything is organized to make files easier to access, manage and preserve.

## ✧ What's Inside?

| Category | Description |
|:---|:---|
| `MB3 Files` | MB3 files and related data resources |
| `iOS Configurations` | iOS configuration profiles and settings |
| `App Logos` | Application icons, logos and branding assets |
| `Images` | Images, banners, wallpapers and illustrations |
| `App Resources` | Application-related resources and assets |
| `Other Data` | Additional files and miscellaneous resources |
